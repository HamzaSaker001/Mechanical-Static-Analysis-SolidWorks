# Mechanical Static Analysis & Design Optimization 🏗️

### Overview
This project focuses on the **Static Structural Analysis** of a mechanical support structure (Chassis) designed in **SolidWorks**. The objective was to evaluate the structural integrity under specific loading conditions and optimize the design for safety and material efficiency.

### Engineering Workflow
1. **3D Modeling:** Created a detailed assembly and part design using SolidWorks.
2. **Preprocessing (FEA):** - Defined material properties (Yield strength, Modulus of elasticity).
   - Applied realistic fixtures (Fixed geometry) and loading conditions (Force/Pressure).
   - Generated an optimized mesh for accurate stress distribution results.
3. **Simulation & Analysis:** - Performed static analysis to identify high-stress areas.
   - Evaluated **Von Mises Stress**, **Displacement**, and **Factor of Safety (FOS)**.
4. **Optimization:** Iterated the design based on simulation results to ensure all components exceed the required safety standards while minimizing weight.

### Key Technical Skills Demonstrated
* **Finite Element Analysis (FEA)** using SolidWorks Simulation.
* **Mechanical Design** & 3D Modeling.
* **Structural Integrity Validation**.
* **Material Selection** based on mechanical properties.

### Software Tools
* **SolidWorks 202X** (CAD & Simulation)
